WHAT TO EXPECT
================================================================================

Your goal is to create 3 working implementations:

1. matrix_multiply_python()
   - Basic Cython with type hints
   - ~500ms for 500×500 matrix

2. matrix_multiply_optimized() 
   - With temporary accumulator for better cache efficiency
   - ~100ms for 500×500 matrix (5x faster!)

3. matrix_multiply_parallel()
   - With OpenMP parallelization
   - ~50ms for 500×500 matrix (10x faster on multi-core!)

Even NumPy baseline (~5ms) is faster, but notice how each optimization
compounds and how simple it is to achieve 10x speedups!
